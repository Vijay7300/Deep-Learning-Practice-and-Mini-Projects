# Deep Learning Practice and Mini Projects

## About This Repository

Welcome to my Deep Learning Practice repository! This repository showcases my hands-on learning, experiments, and mini-projects in Deep Learning, Computer Vision, Natural Language Processing (NLP), and sequence modelling.

The primary objective of this repository is to understand the theoretical foundations of deep learning and apply them to practical problems using Python and popular deep learning frameworks. It includes implementations of neural network architectures, experiments with optimization techniques, and applications of pre-trained models.

From building convolutional neural networks from scratch to fine-tuning transformer-based models, this repository reflects my continuous learning and exploration of modern deep learning techniques.

## Projects and Topics

### 1. Diabetes Prediction
Practice with a diabetes dataset to explore data preprocessing, feature handling, neural network modelling, and predictive analysis on tabular data.

### 2. Fine-Tuning BERT on SQuAD
Fine-tune a pre-trained BERT model for extractive question answering using the Stanford Question Answering Dataset (SQuAD). Explore tokenization, answer-span prediction, transfer learning, and parameter-efficient fine-tuning using LoRA.

### 3. Hyperparameter Tuning in Deep Learning with Optimizers
Experiment with hyperparameters and optimization algorithms to understand their impact on model convergence, training stability, and predictive performance.

### 4. Dogs vs. Cats Classification Using CNN from Scratch
Build a Convolutional Neural Network (CNN) from scratch to classify images of dogs and cats. Explore convolutional layers, pooling, activation functions, regularization, data augmentation, and model evaluation.

### 5. PyTorch LSTM Next-Word Predictor
Develop a next-word prediction model using Long Short-Term Memory (LSTM) networks in PyTorch. Explore text preprocessing, tokenization, word embeddings, sequential learning, and language modelling.

### 6. Transformer-Based NLP
Study transformer architectures and their application to natural language processing. Explore attention mechanisms, contextual representations, and the foundations of modern language models.
